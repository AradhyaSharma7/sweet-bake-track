# Sweet Delight Deliveries

https://sweet-script-baker.lovable.app/#menu

Use this link and check-out this website. I want to upgrade this webpage by linking it to the other webpages. I want you to design many more webpages having more bread/bakery products. 

Suppose the client order's anything from our bakery I want the location of our delivery boy to get shared with the client automatically after ordering. And the delivery boy will receive a consent form that will get signed by the client after the product get's submitted.

I also want a tab named as "Theme" that has light and dark themes in it.
